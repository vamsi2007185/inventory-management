# Inventory Management System

This project is an Inventory Management System that allows users to manage their inventory efficiently. Users can add new items, update existing items, and display the current inventory with details such as quantity and price.

## Features

- **Add Item**: Users can add new items to the inventory by specifying the item name, quantity, and price.
- **Update Item**: Users can update the details of existing items, including changing the quantity and price.
- **Display Items**: Users can view all items in the inventory along with their quantities and prices.

## How to Run the Program

1. Ensure you have Python installed on your machine.
2. Clone the repository or download the project files.
3. Navigate to the `src` directory in your terminal.
4. Run the program using the command:
   ```
   python inventory.py
   ```
5. Follow the on-screen prompts to manage your inventory.

## Usage

- Choose an option from the menu to add, update, or display items.
- Enter the required details as prompted.
- To exit the program, select the exit option from the menu. 

This project is designed to be simple and user-friendly, making inventory management accessible for everyone.
